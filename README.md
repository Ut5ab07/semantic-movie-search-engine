# 🎬 Semantic Movie Search Engine

A semantic search system that understands the **meaning** of user queries to recommend movies using NLP embeddings and vector similarity.

## 🚀 Features
- Semantic search (not keyword-based)
- NLP embeddings using Sentence Transformers
- Vector similarity search using FAISS
- Streamlit-based UI (coming soon)

## 🧠 Project Structure

data/ → raw and processed datasets  
notebooks/ → experiments and exploration  
src/ → core ML and search logic  
app/ → frontend application  

## 🎯 Tech Stack
- Python  
- Sentence Transformers  
- FAISS  
- Streamlit
